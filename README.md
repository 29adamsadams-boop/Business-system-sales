# Business System - Sales Module

This is a group assignment project for building a Sales Management System using Java, GitHub and VS Code.

## Features Implemented
1.  **Record Sale** - US-001 Must Have
2.  **View Sales Report** - US-002 Must Have  
3.  **Apply Discount** - US-003 Should Have
4.  **Search by Customer** - US-004 Could Have
5.  **Export to PDF** - US-005 Won't Have
