# UC-005: Export Sales to PDF

## Description
Allows Business Owner to export sales report to PDF file.

## Actors
Business Owner

## Preconditions
Sales report must be available.

## Main Flow
1. Business Owner selects "Export to PDF"
2. System generates PDF file
3. System downloads the file

## Postconditions
PDF file is created.
